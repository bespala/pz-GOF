Практична робота pz-GOF
Реалізація патернів проєктування GoF на TypeScript
Про проєкт

У межах даної практичної роботи було реалізовано класичні патерни проєктування GoF (Gang of Four) з використанням мови TypeScript.

Основна мета роботи — зрозуміти, як патерни допомагають будувати більш чистий, зрозумілий та гнучкий код, а також спрощують підтримку і подальший розвиток програмних рішень.

У проєкті реалізовано породжувальні, структурні та поведінкові патерни. Кожен патерн винесений в окрему директорію та має власний консольний приклад.

Реалізовані патерни
1. Породжувальні патерни (Creational)

**Factory Method**

Призначення: створення об'єктів без прямої залежності від конкретних класів.
Приклад у проєкті: фабрика створює різні типи транспорту (Car, Ship).
Результат: залежно від параметра створюється потрібний об'єкт.

**Builder**

Призначення: покрокове створення складних об'єктів.
Приклад у проєкті: створення об'єкта користувача (User) через builder.
Результат: об'єкт формується через послідовний виклик методів.

**Singleton**

Призначення: гарантує існування лише одного екземпляра класу.
Приклад у проєкті: конфігураційний клас застосунку.
Результат: усі звернення повертають один і той самий об'єкт.

2. Структурні патерни (Structural)
**Adapter**

Призначення: дозволяє працювати разом класам із несумісними інтерфейсами.
Приклад у проєкті: адаптація старої платіжної системи до нового інтерфейсу.
Результат: старий код використовується без переписування.

**Facade**

Призначення: спрощує взаємодію зі складною системою.
Приклад у проєкті: запуск комп'ютера через один інтерфейс.
Результат: один метод керує декількома внутрішніми компонентами.

**Decorator**

Призначення: дозволяє динамічно розширювати функціональність об'єкта.
Приклад у проєкті: додавання молока до кави.
Результат: об'єкт отримує нову поведінку без зміни базового класу.

3. Поведінкові патерни (Behavioral)
**Strategy**

Призначення: дозволяє змінювати алгоритм роботи під час виконання програми.
Приклад у проєкті: вибір способу оплати.
Результат: можна перемикатися між оплатою карткою та готівкою.


**Observer**

Призначення: дозволяє повідомляти групу підписників про зміни.
Приклад у проєкті: користувачі підписуються на канал новин.
Результат: усі підписники автоматично отримують повідомлення.


Структура проєкту

src/

├── creational/

├── structural/

└── behavioral/

examples/

└── run-all.ts


Встановлення залежностей
npm install

Запуск проєкту
npm run start

**Висновок**

У ході виконання практичної роботи було реалізовано основні патерни проєктування GoF мовою TypeScript.
Практична реалізація показала, що використання патернів дозволяє будувати більш структурований код, зменшувати залежності між компонентами та спрощувати подальший розвиток програмного забезпечення.
